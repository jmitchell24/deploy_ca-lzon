This is just a simple idea I had for a wallpaper that I wanted.

It’s been a while since I worked on this shader rendering code for the site, so I also see as this as an opportunity to give it a bit of TLC.

If you do want to capture this as a wallpaper, I highly recommend that you use supersampling, it significantly reduces the aliasing effects on the wave lines.

The colors are also responsive to the site theme, so play around with that if you are interested (click the gear icon at the bottom of the page).
