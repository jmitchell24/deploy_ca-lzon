The First Week of lzon.ca

Good god! How has it been only a week?

The project so far…

Today marks the first week since I created the git repository for this website. I submitted the first commit on the 21st with the profound and apt message text:

“initial commit”

I’ve been really enjoying working on this. I’ve always been a low-level C++ hacker but this year I’ve been starting to feel like a real, bona-fide web developer. I’ve been working most of this year on my other site, but just this past week I feel I’ve learned a lot.

Here’s some of the features I’ve been working on.

Quote of the Day

I like a good quote, and I also like to over-engineer my code.

At first I had just a single quote, hard coded onto the homepage. In subsequent days I’ve implemented the following:

  • automatic quote rotation in the browser
  • quotes for specific days
  • quotes for specific moods (just got this working today)

I’m sure I’ll have more ideas, features to add in the near future.

Theme Switcher

I had this working very early, but I’ve been slowly refining it. Just yesterday I learned how to use URI Fragments to control state for the popup window. This has made the whole system much simpler, and my popup now interacts correctly with the back button.

Click here to try it out!

Creating Content

I’ve always regarded myself as a ‘competant’ writer. I had decent grades in my English classes through high school, which I have as evidence of some skill despite my self-deprecating personality. Whether the final product is good or not, I know that I have always enjoyed wordcrafting.

If you have followed along with the posts I’ve made in the last week then you will noticed that they were quite personal, despite not being advertised as such. I had to immerse myself in my memories to write them and that was both a good but difficult thing. I’m completely satisfied with what I have written so far.

As of now I feel that I shouldn’t be quite so sentimental, quite so often. I’m OK to share these details of my life here but doing so every day, or even several times per week, might be too much. I’d also like to write more about the true subject of the post. I’ve felt on several days that I hadn’t written as much as I wanted to. There are so many more flavors of Chip Nuts!

I’m happy to have lzon.ca, and look forward to building more and writing more.
