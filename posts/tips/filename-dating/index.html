How to Organize Your Files by Date
Posted March 15, 2026 Updated March 31, 2026 7 min read

Here’s a technique I often use for organizing my files, as well as some useful scripts for generating filenames.

The Technique

Do you have some files or folders that you are trying organize by date? If so you might have naturally started naming them like this.

1. expenses_july-2-2021.pdf
2. expenses_june-10-2022.pdf
3. expenses_august-30-2023.pdf

This works well enough, but what would you do if you wanted to sort these files by their date? Not by the creation date of the file, but your specified date as per the filename? If you tried to sort by the filename you would get the following file order.

1. expenses_august-30-2023.pdf
2. expenses_july-2-2021.pdf
3. expenses_june-10-2022.pdf

If you are trying to find a specific file with this naming scheme then sorting in this way is not helpful. Let’s see what happens if we adjust the filenames.

1. expenses_2021-07-02.pdf
2. expenses_2022-06-10.pdf
3. expenses_2023-08-30.pdf

Much better! Now that the date is represented as numbers ordered by largest to smallest timespan, simple lexicographical sorting now also becomes the same as chronological sorting. Neat, isn’t it?

I use this constantly! I use it throughout the source files for lzon.ca, and anywhere else on my computer where it makes sense to do so. To save time, I created a few different scripts that automatically create these date codes.

Unix Date Formatting

Both scripts use the same command date +%Y-%m-%d to produce the date code. This command uses the date program with a format string. The + sign introduces a format string, where % placeholders are replaced with date components:

  • %Y 4-digit year
  • %m 2-digit month
  • %d 2-digit day

This might seem too obvious to even mention, but I know that I can never remember how these format strings work so I figured it’d be convenient to include this small explanation. Now to go over the actual scripts.

Automating with the Clipboard

This script submits the date code to the operating system’s clipboard. I trigger the script using a simple key combo in GNOME, and can then use Ctrl + V to paste the date code where I need it.

It is intended for a linux-based operating system, running either wl-copy or xclip, or xsel. One of these should be pre-installed on any modern distribution, but check your documentation to be sure. Alternatively, you can just try the script and see if it errors out, that’s what I would do. 😆

 1#!/bin/bash
 2
 3date_str=$(date +%Y-%m-%d)
 4
 5# Try clipboard tools in order of preference
 6if command -v wl-copy &> /dev/null; then
 7    echo -n "$date_str" | wl-copy
 8elif command -v xclip &> /dev/null; then
 9    echo -n "$date_str" | xclip -selection clipboard
10elif command -v xsel &> /dev/null; then
11    echo -n "$date_str" | xsel --clipboard
12else
13    echo "Error: No clipboard tool found. Install one of: wl-clipboard, xclip, xsel"
14    exit 1
15fi

I used this for a while and it worked well. But recently I created a new script that I like better, which I will explain next.

Automating with virtual typing

This script creates virtual key inputs corresponding to the current day’s date code, which amounts to typing out the code automatically. Just like before, I trigger the script using a simple key combo in GNOME.

The following is intended for a linux-based operating system, which has either xdotool, ydotool, or wtype already installed and configured.

On my system I chose to use ydotool, and I’ve named this script type-date.sh

  1#!/bin/bash
  2
  3# ──────────────────────────────────────────────────────────────────────────────
  4#  type-date.sh — Type today's date via simulated keypresses
  5# ──────────────────────────────────────────────────────────────────────────────
  6#  Outputs the current date by typing it into the focused window
  7# ──────────────────────────────────────────────────────────────────────────────
  8
  9set -euo pipefail
 10
 11# ── Colors ───────────────────────────────────────────────────────────────────
 12BOLD=$'\033[1m'
 13DIM=$'\033[2m'
 14GREEN=$'\033[0;32m'
 15RED=$'\033[0;31m'
 16CYAN=$'\033[0;36m'
 17RESET=$'\033[0m'
 18
 19# ── Usage / Help ─────────────────────────────────────────────────────────────
 20usage() {
 21    cat <<EOF
 22
 23${BOLD}type-date.sh${RESET} — Type today's date via simulated keypresses
 24
 25${BOLD}USAGE${RESET}
 26    type-date.sh [options]
 27
 28${BOLD}OPTIONS${RESET}
 29    ${CYAN}--format FORMAT${RESET}  Date format string (default: ${CYAN}%Y-%m-%d${RESET})
 30    ${CYAN}--delay MS${RESET}       Delay in milliseconds before typing (default: ${CYAN}100${RESET})
 31    ${CYAN}-h, --help${RESET}       Show this help message
 32
 33${BOLD}FORMATS${RESET}
 34    Any format string accepted by ${CYAN}date(1)${RESET}. Common examples:
 35
 36    ${DIM}%Y-%m-%d${RESET}       2026-02-23       (ISO 8601, default)
 37    ${DIM}%m/%d/%Y${RESET}       02/23/2026       (US style)
 38    ${DIM}%d.%m.%Y${RESET}       23.02.2026       (EU style)
 39    ${DIM}%B %d, %Y${RESET}      February 23, 2026
 40
 41${BOLD}EXAMPLES${RESET}
 42    ${DIM}# Type today's date in YYYY-MM-DD format${RESET}
 43    type-date.sh
 44
 45    ${DIM}# Type in US date format${RESET}
 46    type-date.sh --format '%m/%d/%Y'
 47
 48    ${DIM}# Add a longer delay before typing (useful for switching windows)${RESET}
 49    type-date.sh --delay 500
 50
 51${BOLD}BEHAVIOR${RESET}
 52    - Simulates keypresses into the currently focused window
 53    - Tries ydotool, then xdotool, then wtype
 54    - A short delay before typing lets you switch focus if needed
 55
 56EOF
 57    exit 0
 58}
 59
 60# ── Parse arguments ──────────────────────────────────────────────────────────
 61FORMAT="%Y-%m-%d"
 62DELAY=100
 63
 64while [[ $# -gt 0 ]]; do
 65    case "$1" in
 66        -h|--help)
 67            usage
 68            ;;
 69        --format)
 70            if [[ -z "${2:-}" ]]; then
 71                echo -e "${RED}Error:${RESET} --format requires a format string"
 72                exit 1
 73            fi
 74            FORMAT="$2"
 75            shift
 76            ;;
 77        --delay)
 78            if [[ -z "${2:-}" ]]; then
 79                echo -e "${RED}Error:${RESET} --delay requires a value in milliseconds"
 80                exit 1
 81            fi
 82            DELAY="$2"
 83            shift
 84            ;;
 85        -*)
 86            echo -e "${RED}Error:${RESET} Unknown option: $1"
 87            echo "Run ${CYAN}type-date.sh --help${RESET} for usage."
 88            exit 1
 89            ;;
 90        *)
 91            echo -e "${RED}Error:${RESET} Unexpected argument: $1"
 92            echo "Run ${CYAN}type-date.sh --help${RESET} for usage."
 93            exit 1
 94            ;;
 95    esac
 96    shift
 97done
 98
 99# ── Generate date string ────────────────────────────────────────────────────
100DATE_STR=$(date +"$FORMAT")
101
102# ── Find typing tool and type ───────────────────────────────────────────────
103sleep "$(awk "BEGIN {printf \"%.3f\", $DELAY / 1000}")"
104
105if command -v ydotool &>/dev/null; then
106    ydotool type "$DATE_STR"
107elif command -v xdotool &>/dev/null; then
108    xdotool type "$DATE_STR"
109elif command -v wtype &>/dev/null; then
110    wtype "$DATE_STR"
111else
112    echo -e "${RED}Error:${RESET} No typing tool found (tried ydotool, xdotool, wtype)"
113    exit 1
114fi

And if you needed it, here’s a systemd service file that will launch ydotool on startup. My operating system didn’t create this automatically when I installed ydotool.

 1# ydotool needs its daemon (ydotoold) running. The user service is at
 2# /etc/systemd/user/ydotool.service — it has a 3s startup delay because
 3# the /dev/uinput ACL isn't ready at boot. If ydotool stops working after
 4# a reboot, check: systemctl --user status ydotool
 5# To restart: systemctl --user restart ydotool
 6#
 7# Service file (/etc/systemd/user/ydotool.service):
 8
 9[Unit]
10Description=Starts ydotoold service
11
12[Service]
13Type=simple
14Restart=always
15ExecStartPre=/bin/sleep 3
16ExecStart=/usr/bin/ydotoold --socket-path="%t/.ydotool_socket" --socket-own="%U:%U"
17ExecReload=/usr/bin/kill -HUP $MAINPID
18KillMode=process
19TimeoutSec=180
20
21[Install]
22WantedBy=default.target
